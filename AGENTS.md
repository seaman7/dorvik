# DORVIK Development Guidelines

## Language & Tooling Preference
- **Pure JavaScript Only**: Use `.js` and `.jsx` exclusively.
- **No TypeScript**: Do not add TypeScript, `.ts`, `.tsx`, `tsconfig.json`, or `@types/*` dependencies.
- **Framework & Styling**: Next.js (App Router), Tailwind CSS v4, Framer Motion, Lucide React icons.
